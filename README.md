# 🦊 Ortografía Mágica

Aplicación interactiva y lúdica para el aprendizaje y práctica de ortografía en la escuela primaria (1.° a 7.° grado).

## ✨ Características

- 🗺️ **4 Territorios del lenguaje:** Bosque de las Letras, Castillo de las Palabras, Montaña de los Acentos y Biblioteca de los Maestros.
- 📖 **Páginas de aprendizaje:** Reglas claras, ejemplos sonoros con síntesis de voz, errores comunes y trucos mnemotécnicos.
- 🎮 **4 Modalidades dinámicas de práctica:**
  - Opción múltiple
  - Completar palabras
  - Ordenar sílabas
  - Corrección de oraciones
- 🏆 **Bitácora y progreso:** Registro de rachas, niveles, insignias desbloqueables y áreas de mejora.
- 🔒 **Sin registro ni contraseñas:** Guardado 100% local en el navegador (Local Storage).
- 🔊 **Audio y pronunciación:** Sintetizador de voz y efectos sonoros interactivos sin dependencias externas.

## 🚀 Tecnologías

- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/)

## 🛠️ Instalación y ejecución local

```bash
# Instalar dependencias
npm install

# Modo desarrollo
npm run dev

# Compilar para producción
npm run build
```
